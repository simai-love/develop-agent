# 画面例の再現条件

画像は現行の `app/static/` を Chromium で描画し、API 応答だけを架空の「メモ検索の改善」に置き換えて撮影しました。画面幅は 1500 px、高さは通常 1000 px、`04-plan.png` のみ質問と計画を収めるため 1400 px です。実タスクのデータ、CLI の会話、秘密情報は使っていません。再現にはタスクの `validation/capture-screenshots.cjs` を使います。画面の状態は撮影用の模擬応答なので、実際の実装や検証を完了した証拠ではありません。

## 01-home.png

[画像を開く](01-home.png)。プロジェクト一覧を空にして起動します。サンプルデータはありません。[このアプリでできること](../user-guide.md#このアプリでできること)に対応します。

## 02-create.png

[画像を開く](02-create.png)。空のホームから「プロジェクトを作成」を押し、プロジェクト「メモ検索の改善」、ブランチ名 `memo-search`、最初のタスク「メモを検索できるようにする」を入力します。[プロジェクトと最初のタスクを作る](../user-guide.md#プロジェクトと最初のタスクを作る)に対応します。

## 03-task.png

[画像を開く](03-task.png)。前項のプロジェクトを作成し、計画が空の最初のタスクを開きます。[プロジェクトと最初のタスクを作る](../user-guide.md#プロジェクトと最初のタスクを作る)に対応します。

## 04-plan.png

[画像を開く](04-plan.png)。01 画面で「最初に検索する対象は？」という Agent の質問と、架空のメモ検索計画を表示します。[01 計画を相談して保存する](../user-guide.md#01-計画を相談して保存する)に対応します。

## 05-execute.png

[画像を開く](05-execute.png)。実装可否判定を有効にして「実装に進む」を押します。サンプルは架空の保存済み計画です。[実装を始める](../user-guide.md#実装を始める)に対応します。

## 06-running.png

[画像を開く](06-running.png)。実装中の API 応答を返してタスクを開き、架空の作業履歴を 1 件表示します。[実装を始める](../user-guide.md#実装を始める)に対応します。

## 07-result.png

[画像を開く](07-result.png)。検証済みタスクの 02 を開き、架空の `REPORT 01` と資料 `sample.json` を表示します。[02 検証結果と資料を見る](../user-guide.md#02-検証結果と資料を見る)に対応します。

## 08-complete.png

[画像を開く](08-complete.png)。以前の確認画面で、架空のブランチ、コミット文、対象 `src/search.py` を表示した例です。現在の葉タスクの確認画面にはコミットメッセージの編集欄があります。操作は[タスクとプロジェクトを完了する](../user-guide.md#タスクとプロジェクトを完了する)を参照してください。

確認文はアプリが `window.confirm` に渡す実際の文字列を、撮影用のページ内ダイアログに表示したものです。ブラウザ固有の確認窓の外観は環境によって異なります。
